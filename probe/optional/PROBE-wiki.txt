h2. P10 code macro: cpp

{code:language=cpp|title=fs/mtfs/gc.c|linenumbers=true}
static int mtfs_gc_zone(struct mtfs_sb_info *sbi, unsigned int zno)
{
	struct mtfs_zone *z = &sbi->zones[zno];

	if (z->valid_blocks == 0)
		return 0;
	return migrate_zone(sbi, z);
}
{code}

h2. P26 긴 문단 (자동 줄바꿈)

zone size를 48M으로 잡으면 checkpoint 주기마다 write pointer가 zone 경계에 정렬되는지 확인해야 하고, 그렇지 않으면 GC가 victim zone을 고를 때 valid block 수를 과다 계산해 불필요한 migration이 발생한다. 이 문단이 페이지 폭에서 자연스럽게 감기는지 본다.
